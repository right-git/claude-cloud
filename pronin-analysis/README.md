## 1. Коротко

**Это не монтаж, а код.** Каждый кадр — React-компонент в **Remotion**, в уроке 1 он прямо назван главным движком. Код пишет **Claude Code** (или Codex) внутри папки проекта. В этой папке заранее лежат:

- **дизайн-система**: токены, плашки, приёмы, сетка, цвет;
- **библиотека готовых анимационных компонентов**;
- **скиллы** на каждый этап: новый ролик, круг правок, звук, закрытие, упаковка;
- **хуки**, которые после каждой правки сами проверяют типы, линтер и каталог компонентов;
- **память**: правила, журнал, статус, решения, уроки.

Сам автор пишет только текст и выбирает варианты. Озвучку делает **ElevenLabs**, привязку каждого слова ко времени — **Whisper** (через OpenAI API). Агент по этим таймкодам раскладывает события на экране и рендерит MP4.

**Ролики выглядят «дорого» и не похоже на шаблон по трём причинам:**
1. **Одна строгая дизайн-система** на все ролики: шрифт, строчные буквы, сетка фона, стеклянные карточки, blur-анимации.
2. **Каждый ролик — отдельный «формат-контейнер»**: блок-схема с камерой, топ с вердиктами, демо системы, непрерывный продуктовый показ, приложение-каталог. Вариативность задаётся на уровне формата, а не отдельных эффектов. В v2 он прямо говорит: *«из коробки все ставят те же композиции и плашки. Если не выстроишь вариативный пайплайн, через полгода конкурировать будет невозможно»*.
3. **Правило «показывай, а не подписывай»**: субтитров нет. На экране 2–5 слов пересказа. Существительные из речи превращаются в предметы и живой интерфейс: «2 месяца» — иконка календаря, «без лица» — балаклава, «на автомат» — тумблер, «засрёшь контекст» — полоса «расход 0→100%».

## 2. Пайплайн

Собран из урока 1 и ролика v3. В v3 на экране так и написано: «Заметки → ElevenLabs → Whisper → Claude Code».

```
1. Текст (Заметки)                 ← пишешь сам: примеры, подача, шутки
2. Озвучка (ElevenLabs, Eleven v3) ← агент генерирует варианты, ты выбираешь темп и дубль
3. Таймкоды (Whisper, word-level)  ← агент получает {word, start, end} для каждого слова
   «озвучка разбивается на тайминги для битов», т.е. на смысловые сцены
4. План экранов                    ← агент предлагает экраны, ты проверяешь мысль и порядок
5. Экраны (Remotion)               ← агент собирает из библиотеки компонентов и ассетов
6. Проверка                        ← агент проверяет данные (хуки, линтер, нет ли битых путей
                                     к картинкам), ты смотришь превью в Remotion Studio / Storybook
7. Рендер MP4                      ← у v4 ушло 50 мин работы автора + 30 мин рендера
```

Что ещё сказано в уроках:
- **Сначала короткий тестовый файл**, потом добавляются стиль, озвучка и несколько экранов. Если сразу просить большой ролик с персонажем и десятком эффектов, получится «дичь», в которой трудно разобраться.
- **Первые ролики делаются с контролем каждого шага.** Выбранный стиль и порядок работы агент сохраняет в память. Автоматизацию включают только после этого (v1, урок 13).
- **Если нужного инструмента генерации нет, агент должен сказать об этом до сборки**, а не вставить в кадр путь к несуществующей картинке. Это правило для проверки.
- **Две связки:**
  - Claude Code + ElevenLabs + OpenAI API (Whisper и генерация картинок);
  - Codex с подпиской ChatGPT + ElevenLabs. В v1 он советует Codex, «чтобы отдельно не платить за картинки».
- **Storybook — «витрина»**: там агент собирает цвета, шрифты и компоненты в одном месте, а автор смотрит и правит (v1, v5).

### Структура проекта (дословно с экрана в v3)

```
система/
├── визуал  — «шрифты и компоненты»: токены, плашки, приёмы, сетка, цвет
├── скиллы  — «для создания и правок»: новый ролик, круг правок, звук, закрытие, упаковка
├── хуки    — «по событиям»: типы, каталог, линтер, старт, коммит
└── память  — «чтобы всё помнил»: правила, журнал, статус, решения, уроки

Окно «Целая система — всё, из чего собран ролик»:
компоненты · скиллы · хуки · агенты · правила · проверки ·
токены · витрина · сборка · журнал · память · статус
```

Как это, скорее всего, выглядит в Claude Code:

| На экране | Реализация в Claude Code |
|---|---|
| визуал | `src/tokens.ts`, `src/components/*` (плашки, приёмы), `src/grid.ts`; **витрина** — Storybook или showcase-композиция в Remotion Studio |
| скиллы | `.claude/skills/new-video`, `revision-round`, `sound`, `outro`, `packaging` |
| хуки | `.claude/settings.json`: PostToolUse → `tsc` (типы), eslint (линтер), регенерация каталога компонентов; SessionStart (старт); авто-коммит |
| агенты | `.claude/agents/*`, например отдельный ревьюер кадров |
| память | `CLAUDE.md` + `memory/rules.md`, `journal.md`, `status.md`, `decisions.md`, `lessons.md` |

## 3. Дизайн-ДНК: общее во всех 5 роликах

**Холст**
- Фон почти чёрный, `#0E1010` / `#111` / `#121212`. На нём сетка-миллиметровка с шагом ~56 px при ширине 720, это ≈84 px при 1080. Линии 1 px с прозрачностью 3–4 %. Сетка **закрыта радиальной маской**: видна только в центре и гаснет к краям. Это главный признак «одного канваса».
- Вторая тема — белая `#FFF` с сеткой `#EEF0F0`. Темы меняются по смыслу (шутка, демо интерфейса) через серый, диагональную шторку или crossfade.
- Иногда появляется «мир» для эмоции: размытое небо с плёночным зерном, оранжевый или фиолетовый радиальный градиент (v1, v4).

**Типографика**
- Один геометрический гротеск в духе **Google Sans / Product Sans**. Бесплатные замены с кириллицей: **Onest**, Manrope, Golos.
- **Всё строчными**, без точек, трекинг от 0 до −1 %.
- Заголовок: **6–8.5 % ширины кадра**, вес 600, 1–3 слова в строке, не шире 75 % кадра.
- Иерархия держится на **цвете, а не на размере**. Ключевые слова белые, второстепенные серые `#8C8C8C`.
- Заголовок рождается по центру (y ≈ 45–50 %), а когда появляется визуал, **пружиной уезжает вверх** (y ≈ 12–17 %). Нижние ~30 % кадра почти пустые: там интерфейс Instagram.

**Акценты**
- Формула **«слово [объект] слово»**: иконка, 3D-предмет или аватар стоит прямо в строке. Примеры: «второй 🧠 мозг», «база [memoji] знаний», «поэтому [аватар] сел».
- Выделение слова как в редакторе: синяя плашка `#1E3A5F` и ручки-капли `#3B8BF5` (v3). Или pill-заливка: маджента `#E6168F` в v1, чёрная в v4.
- Pill с логотипом внутри строки («поставил волшебный [GitHub] скилл»).
- Мелкие серые ремарки, соединённые с объектами пунктирными стрелками или дугами («2 шаг», «лучше это»).
- Одновременно 1–2 акцентных цвета: синий `#3B8BF5`, маджента, лайм `#A3D957`, розовый `#F062A8`.

**Поверхности**
- «Стеклянные» карточки: заливка `#1A1A1A`–`#1E1E1E`, обводка 1–1.5 px `rgba(255,255,255,.15–.35)` светлее сверху, радиус 24–30 px при 720. Настоящего backdrop-blur нет, это имитация.
- Pill с радиусом 999 и внутренним бликом сверху, как стеклянная кнопка macOS.
- В тёмной теме теней почти нет. В светлой тень мягкая: `0 20px 60px rgba(0,0,0,.08)`.

**Ассеты**
- **Весь интерфейс свёрстан кодом**: поле ввода чата, чат, код-редактор, профили Instagram и Telegram, бот, мини-приложение, тумблер, графики. Данные передаются через props.
- **Объекты-метафоры в едином глянцевом 3D-стиле**, почти наверняка GPT-image: иллюминатор, балаклава, хромированный ключ, мозг с USB-C, мусорка, золотой унитаз, вагон, 3D-папка, хромовые сфера, тор и куб. Один объект на один смысл.
- Логотипы сервисов — SVG. Memoji или мультяшный аватар автора — сквозной «подписной» элемент. Курсор macOS — SVG.

## 4. Словарь анимаций: 12 приёмов, из которых собраны все 5 роликов

Все значения даны для 30 fps.

| # | Приём | Параметры | Где встречается |
|---|---|---|---|
| 1 | **Blur-in по словам** — главный текстовый эффект | opacity 0→1, blur 8–12→0, translateY 8–12→0 (иногда scale 1.08→1), 5–8 кадров, ease-out cubic. Старт по таймкоду слова из Whisper, раньше на 0–2 кадра | все |
| 2 | **Blur-typewriter** | ~1 символ за кадр, последние 1–2 символа ещё размыты. Обратный набор работает как «стирание» | v2, v4 |
| 3 | **Живое перецентрирование** | слот нового слова раскрывается по ширине, строка плавно перецентрируется. Сверху — re-center всего стека пружиной | v2, v3, v4 |
| 4 | **Pop с перелётом** | scale 0.3–0.6 → 1.05–1.08 → 1 плюс blur 6–8→0, spring (damping 11–12, stiffness 180–200, mass 0.6), 7–10 кадров, stagger 2–3 кадра | все |
| 5 | **Push-layout** | объект выезжает снизу и **той же пружиной** выталкивает заголовок вверх, ~15 кадров, без overshoot | v1, v3 |
| 6 | **Shared-element / морф** | один элемент переживает смену сцены: «1» превращается в «100+», поле ввода — в пузырь, pill — в карточку, папка — в иконку окна, одна карточка CTA меняет высоту по шагам. Spring 8–15 кадров, контент меняется через blur | все |
| 7 | **Уход сцены через blur** | blur 0→10–12 + fade (+ scale 0.85–0.9 = «recede»), 6–10 кадров, потом 3–6 кадров пустой сетки | все |
| 8 | **Whip / push с направленным motion blur** | 5–7 кадров, смаз 20–40 px по оси движения. SVG `feGaussianBlur stdDeviation="X 0"` или `@remotion/motion-blur` | v1, v4 |
| 9 | **Камера по холсту** | длинное полотно (блок-схема), камера едет по пунктиру за ~14–18 кадров, ease-in-out, blur по скорости и лёгкий zoom-dip до 0.9 | v1, v4 |
| 10 | **Рисование пути** | `stroke-dashoffset` за 10–20 кадров: пунктирные стрелки, дуги «N шаг», графики, ветки-кривые Безье | все |
| 11 | **Курсор macOS** | кривая Безье ease-in-out 12–18 кадров. Клик: scale 1→0.85→1 плюс ripple и сразу реакция интерфейса. Drag: элемент scale 1.03 + тень, в полёте уменьшается | v1–v4 |
| 12 | **Живой холд** | статичных кадров нет. Idle-float ±2 px и ±0.5°, shimmer-блик по тексту, karaoke-волна по подписям, медленный пан скриншотов 25–40 px/с | все |

Остальное — вариации этих приёмов: барабан цифр, 3D-карусель прошлых роликов, слот-барабан с глубиной резкости, count-up, прогресс-бары, 3D-выпрямление карточки, Island-морф таймера, zoom-through сквозь предмет, диагональная шторка смены темы. Код для каждого есть в разборах `videos/v*.md`, раздел 4.

**Ритм:** 2–4 визуальных события в секунду, новый «экран» каждые ~2.4 с, переходы 6–12 кадров. **Жёстких склеек нет почти нигде**: весь ролик — один непрерывный холст, и почти каждое движение смягчено блюром.

### Базовый код

```tsx
// 1. Слово по таймкоду Whisper
export const Word: React.FC<{w: string; at: number; accent?: boolean}> = ({w, at, accent}) => {
  const f = useCurrentFrame(); const {fps} = useVideoConfig();
  const p = spring({frame: f - Math.round(at * fps) + 2, fps, config: {damping: 200}, durationInFrames: 7});
  return <span style={{display: 'inline-block', marginRight: '.28em', opacity: p,
    filter: `blur(${(1 - p) * 10}px)`, transform: `translateY(${(1 - p) * 10}px)`,
    color: accent ? '#fff' : '#8C8C8C', fontWeight: accent ? 600 : 400}}>{w}</span>;
};

// 4. Pop
const s = spring({frame: f - start, fps, config: {damping: 12, stiffness: 200, mass: 0.6}});
const pop = {transform: `scale(${0.3 + 0.7 * s})`, opacity: Math.min(1, s * 1.5), filter: `blur(${Math.max(0, 1 - s) * 8}px)`};

// 7. Уход сцены
const t = interpolate(f, [end - 8, end], [0, 1], {extrapolateLeft: 'clamp', extrapolateRight: 'clamp', easing: Easing.in(Easing.cubic)});
const out = {opacity: 1 - t, filter: `blur(${t * 12}px)`, transform: `scale(${1 - 0.1 * t})`};

// 9. Камера по холсту с blur по скорости
const p = interpolate(f, [at, at + 14], [0, 1], {extrapolateLeft: 'clamp', extrapolateRight: 'clamp', easing: Easing.inOut(Easing.cubic)});
const v = Math.sin(Math.PI * p);
<AbsoluteFill style={{transform: `translateY(${-(from + (to - from) * p)}px) scale(${1 - 0.1 * v})`,
  filter: `blur(${v * 6}px)`}}><FlowCanvas /></AbsoluteFill>

// Фон: сетка с радиальной маской
<AbsoluteFill style={{background: '#111',
  backgroundImage: 'linear-gradient(rgba(255,255,255,.035) 1px,transparent 1px),linear-gradient(90deg,rgba(255,255,255,.035) 1px,transparent 1px)',
  backgroundSize: '84px 84px',
  maskImage: 'radial-gradient(ellipse 80% 70% at 50% 45%, #000 40%, transparent 100%)'}} />
```

## 5. Почему каждый ролик выглядит уникально

Дизайн-система и словарь анимаций общие. **Меняется формат-контейнер**, и под каждый пишется свой набор «виджетов». По 5 роликам видно по крайней мере 5 архетипов:

| Архетип | Ролик | Контейнер | Фирменная фишка |
|---|---|---|---|
| **Инструкция-блок-схема** | v1 | длинный вертикальный холст с пунктиром и ветками | камера едет по схеме, pill раскрывается в живой интерфейс (ElevenLabs TTS с текстом этого же ролика) |
| **Топ с вердиктами** | v2 | пункт = заголовок «слово [объект] слово» → виджет-метафора → вердикт | смена светлой и тёмной темы по пунктам, курсор тащит файлы и чаты в мусорку |
| **Показ системы** | v3 | карточки, которые рождаются друг из друга (split), сетка 2×2, цепочка шагов | мета: 3D-карусель его прошлых роликов, выделение слова как в редакторе |
| **Непрерывное продуктовое демо** | v4 | чат, стрим ответа, табы, drag-and-drop, таймер | ни одной склейки, направленный motion blur, ролик внутри самого ролика |
| **Приложение-каталог** | v5 | профиль, pill-табы, лента карточек со скриншотами сайтов | цвет категории окрашивает весь интерфейс, слот-барабан с глубиной резкости, вихрь иконок |

Общие правила сценария, которые делают ролик «авторским»:
1. **Хук за 2 с**: цифра или факт + предмет + движение («2 месяца», «за [барабан] год», «Июль 2» в иллюминаторе) и сразу доказательство (карусель роликов, профиль с 22 тыс.).
2. **Самоирония и мета**: «какой в 🍑 скилл», «всё гавно → не гавно», в карусели его собственные ролики, в чате намеренно уродливые черновики.
3. **Существительное становится объектом, действие — интерфейсом.** Никогда не подписывать то, что можно показать.
4. **CTA — интерактивная воронка**: курсор кликает «профиль → t.me → канал → бот → мини-приложение», и одна карточка морфится между этими состояниями. Одинаковый во всех 5 роликах: это переиспользуемый компонент.

## 7. Как собрать такое же у себя

1. **Каркас:**
   ```bash
   npx create-video@latest   # шаблон Remotion
   ```
   Добавь `@remotion/google-fonts` (Onest), `@remotion/motion-blur`, `@remotion/layout-utils`, `@remotion/media-utils`. Композиция 1080×1920, 30 fps.
2. **Токены** в `src/tokens.ts`:
   - цвета фона и текста, акценты;
   - шрифт и кегли в % от ширины кадра (заголовок 7 %, подпись 4 %, ремарки 2.5 %);
   - радиусы (24 / 30 / 999);
   - тайминги: `enter = 7f`, `stagger = 3f`, `pop spring {12, 200, .6}`, `exit = 8f`, `camera = 14f`.
3. **Библиотека компонентов**, раздел 4. Минимальный набор для первого ролика:
   - `Canvas` (сетка + маска + темы), `Word` / `Title` (по Whisper), `Pop`, `PushLayout`, `SceneOut`;
   - `GlassCard`, `Pill`, `InlineIcon`, `DashedPath`, `Cursor`, `CtaFunnel`.

   Потом добавляй `CameraCanvas`, `MorphCard`, `ChatStack`, `ThemeWipe`, `WhipPan`.
4. **Данные** — `public/<ролик>/`:
   - `voice.mp3` из ElevenLabs;
   - `words.json` из Whisper (`timestamp_granularities=["word"]`);
   - `plan.json`: биты, у каждого бита заголовок из 2–5 слов, слово-триггер для каждого события, тип сцены (архетип), ассеты.
5. **`CLAUDE.md`** — правила из этого разбора:
   - строчные буквы;
   - ≤5 слов на экране, без субтитров;
   - существительное → объект;
   - уход сцены через blur;
   - никаких статичных кадров;
   - нижние 30 % пустые;
   - не выдумывать пути к картинкам;
   - перед сборкой показать план экранов.
6. **Скиллы:** `new-video` (текст → озвучка → words → план → сборка), `revision-round` (правки по списку замечаний + превью), `sound`, `outro` (CTA), `packaging` (рендер, обложка, подпись к посту).
7. **Хуки:** после правки файлов — `tsc --noEmit`, eslint и проверка, что все ассеты из `plan.json` существуют. На старте сессии — прочитать `memory/status.md`.
8. **Витрина:** Storybook или отдельная композиция `Showcase` в Remotion Studio, чтобы видеть все компоненты сразу.
9. **Первые 3–5 роликов собирай вручную вместе с агентом.** После каждого пиши в `memory/lessons.md`, что сломалось. Автоматизацию включай, только когда процесс стабилен. Это совет самого автора.

## Ограничения разбора

- Разобрано 5 роликов. Архетипов у автора, вероятно, больше.
- Размеры, цвета и тайминги оценены по пережатому видео 720p (один ролик в 540p): точность ±10–20 %. Шрифт определён на глаз.
- Транскрипт сделан моделью Whisper small, концы некоторых фраз обрезаны.
- Структура проекта взята с экрана v3. То, как она устроена внутри Claude Code (раздел 2), — гипотеза.
- Содержимое платных уроков 2–14 не видно. О нём можно судить только по заголовкам и описанию курса.
