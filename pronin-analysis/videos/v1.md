## Краткое резюме (v1)

- **Ролик:** 44 с, 720×1280 @30fps (рендер, скорее всего, 1080×1920). Тема: «блог без лица, ролики делает нейронка» и стек Codex/Claude → ElevenLabs → Remotion + Storybook → HeroUI → Pinterest → posts.design → итерации в чате → автоматизация. Жёстких склеек нет: все переходы длятся 6–12 кадров и почти все сделаны через blur.
- **Хук:** «я запустил блог» проявляется по словам из блюра. Снизу выезжает 3D-иллюминатор с розовым календариком «Июль 2», заголовок при этом выталкивается вверх. - **Анимации:**
  - Слова появляются через blur 12→0 px, ≈6 кадров, шаг 3–4 кадра, привязаны к таймстемпам Whisper.
  - Объект выезжает снизу на spring (≈15 кадров) и синхронно выталкивает заголовок вверх.
  - Pop: scale 0.3→1.08→1 с блюром.
  - Отдельно проработаны zoom-through-портал, whip-pan с направленным блюром, recede (отъезд с затемнением) и переход фона тёмный ↔ белый через серый.

- **Синхронизация с речью:** караоке нет. На экране короткий перефраз фразы, а pop-ы стоят точно на опорных словах («здесь / или здесь / лучше здесь / сюда»). Старый текст уходит вместе со всей сценой.
- **Уникальность:**
  - Предметы-метафоры (иллюминатор, балаклава, хромированный ключ, тумблер) вместо россыпи иконок.
  - Проход сквозь предмет в следующую сцену.
  - Блок-схема с камерой.
  - Pill ElevenLabs раскрывается в карточку Text to Speech, в которой написан текст этого же ролика.

  - CTA показан интерактивно курсором.
- **Ассеты:** предметы-метафоры сгенерированы (GPT-image). Логотипы брендов — SVG. Реальные скриншоты профилей стоят в HTML-мокапах. Весь UI (плитки HeroUI, чат, карточки Telegram) свёрстан кодом.

## 3. Дизайн-система

- Варианты раскладки: заголовок сверху + подпись снизу (ключ); визуал сверху + заголовок в нижней трети (posts.design).

## 4. Каталог приёмов (с Remotion)

**A. Blur-in по словам (главный текстовый приём).** Каждое слово: opacity 0→1, blur 12→0, иногда scale 1.08→1 или translateY 8→0. Длительность ≈6 кадров, ease-out. Stagger 3–4 кадра или привязка к таймстемпу Whisper. Строка сразу свёрстана целиком (слова с `opacity:0`), поэтому переносы не прыгают.
```tsx
const BlurWord = ({text, start}) => {
  const f = useCurrentFrame();
  const p = interpolate(f - start, [0, 6], [0, 1], {extrapolateLeft:'clamp', extrapolateRight:'clamp', easing: Easing.out(Easing.cubic)});
  return <span style={{display:'inline-block', marginRight:'0.25em', opacity:p,
    filter:`blur(${(1-p)*12}px)`, transform:`translateY(${(1-p)*8}px) scale(${1.08-0.08*p})`}}>{text}</span>;
};
```

**B. Layout push.** Объект въезжает снизу, заголовок одним и тем же spring-ом едет из центра вверх:
```tsx
const e = spring({frame: f - objStart, fps, config:{damping:20, stiffness:120}});
const titleY = interpolate(e, [0,1], [900, 290]); const objY = interpolate(e, [0,1], [1920, 620]);
```

**C. Pop pill/иконки.** scale 0.3→1.08→1 + blur 8→0 + opacity, ≈7–9 кадров:
```tsx
const s = spring({frame: f - start, fps, config:{damping:12, stiffness:200, mass:0.6}});
style={{transform:`scale(${0.3+0.7*s})`, opacity:Math.min(1,s*1.5), filter:`blur(${Math.max(0,1-s)*8}px)`}}
```

**D. Zoom-through (портал).** Следующая сцена лежит снизу. Старая сцена с прозрачной «дырой» в форме окна масштабируется ×1→×5 вокруг центра окна (ease-in, 8–10 кадров, blur 0→12, в конце fade). Для тумблера вариант проще: объект летит на камеру, а фон отдельно темнеет через серый.

**E. Камера по холсту (сердце ролика).** Длинный вертикальный flow-холст; keyframes Y для каждого узла. Перелёт ≈14 кадров, `Easing.inOut(Easing.cubic)`, velocity `v = sin(πp)`. Во время перелёта: `scale(1 - 0.1v)` и направленный блюр через SVG `feGaussianBlur stdDeviation="0 {v*14}"` (или `@remotion/motion-blur` — дороже при рендере). Пунктир — SVG path (dash ≈30/20, stroke 3, `#4A4C4C`), ветки — кубические Безье, draw-on маской.
```tsx
const p = interpolate(f, [at, at+14], [0,1], {extrapolateLeft:'clamp', extrapolateRight:'clamp', easing:Easing.inOut(Easing.cubic)});
const y = from + (to-from)*p, v = Math.sin(Math.PI*p);
<AbsoluteFill style={{transform:`translateY(${y}px) scale(${1-0.1*v})`, filter:'url(#vblur)'}}><FlowCanvas/></AbsoluteFill>
```

**F. Whip-pan.** Контент уезжает на 40–60% ширины за 5–6 кадров с горизонтальным блюром 20–30 px, новый въезжает с противоположной стороны. Фон меняется отдельным слоем и чуть раньше. Направления чередуются (10.3 с — влево, 12.6 с — вправо, 36.5 с — влево).

**G. Recede.** scale 1→0.85–0.9, translateY ±80, blur 0→10, brightness →0, ≈9–10 кадров. Новый заголовок приезжает с противоположной стороны. Используется на 5.8, 23.7, 25.4, 27.3, 29.0 с (на 29.0 фон переходит тёмный→белый через серый).

**H. Morph-карточка.** Контейнер анимирует width/height/radius spring-ом (damping 22, stiffness 160):
```tsx
const m = spring({frame: f - morphAt, fps, config:{damping:22, stiffness:160}});
const w = interpolate(m,[0,1],[280,820]), h = interpolate(m,[0,1],[96,560]);
// старое содержимое: opacity 1-m, blur m*6; новое: opacity interpolate(m,[0.5,1],[0,1])
```

**I. Stagger-сетки.**
- HeroUI: 3×5, шаг 2 кадра, scale 0.85→1 + blur; часть плиток — скелетоны.
- Pinterest masonry: 2 колонки, правая смещена вниз, плитки растут из точки (scale 0.2→1.05→1), шаг 3 кадра.
- posts.design: карточки падают сверху, потом вся лента медленно едет (эффект бесконечного скролла).

**J. Чат.** Сообщения анкерятся снизу. Новое: blur-in + scale 0.85→1 (origin — сторона аватара) + translateY 20→0, ≈7 кадров; весь стек смещается вверх spring-ом на высоту нового сообщения. Аватары — круги ≈80 px на белой подложке с тенью.

**K. Курсор.** SVG-стрелка macOS ≈48 px. Перемещение — ease-in-out за 12–18 кадров, без дуги. Клик: scale 1→0.85→1 за 4 кадра, и сразу реакция UI.

**L. Тумблер.** Ручка — spring ≈8 кадров с лёгким overshoot. Трек: `interpolateColors` `#E6E8E8`→`#4494EE`. Подписи меняют цвет и вес синхронно.

## 5. Синхронизация с речью
- Строгого караоке нет, но слова заголовка появляются по word-level таймстемпам (или на 1–3 кадра раньше). Pop-элементы и клики стоят точно на опорных словах: «здесь», «или здесь», «лучше здесь», «вот это», «сюда».
- На экране не субтитры, а **сжатый перефраз** на 2–5 слов. Остаток фразы передаётся визуалом (календарь «Июль 2», «2026 года»).
- Одновременно видно 1 заголовок + 1 подстрока + визуал.
- Предыдущий текст не исчезает по словам: он уходит вместе со всей сценой в переходе.
- Ключевые слова: pill «нейронка», лайм «лучше это», жирный «автомат».
- В сцене-холсте «текстом» становятся сами pill-узлы — речь визуализирована схемой, а не словами.

## 6. Переходы
Жёстких склеек нет. Типы переходов:
1. **Zoom-through портал**: 2.3 с (иллюминатор → небо), 39.3 с (тумблер → тёмный экран «база знаний»).
2. **Карусель мокапов** внутри сцены: 4.4 с.
3. **Recede**: 5.8, 23.7, 25.4, 27.3, 29.0 с.
4. **Смена фона отдельным слоем + whip-pan контента**: 10.2, 12.5, 36.4 с.
5. **Камера по холсту**: 13.3, 17.4, 19.8 с — единственный «настоящий» camera rig в ролике.
6. **Push-up заголовка** при появлении объекта: 0.5, 3.0, 7.2 с.
7. **Shared-element morph**: 18.2 с, 42–43.6 с.
8. **Переход фона тёмный ↔ белый через серый** с одновременным blur/scale контента: 29.0, 39.3 с.

Все переходы 6–12 кадров, почти везде есть gaussian или направленный motion blur — это главный «клей» стиля.

## 7. Ассеты
- **Иллюминатор, балаклава, хромированный ключ** — GPT-image / 3D-рендеры на прозрачном или чёрном фоне (у балаклавы фон совпадает с фоном ролика). Анимация: выезд снизу, zoom-through, whip.
- **Календарик** — HTML/CSS-компонент (шрифт тот же, что в ролике). Pop внутри окна.
- **Небо** — генерация или сток + CSS-зерно. Работает как «продолжение» окна.
- **iPhone-мокапы** — реальные скриншоты профилей IG и TG («03:16», 22 тыс.) в HTML-рамке с Dynamic Island. Выезд снизу, карусель, зелёная плашка на цифре.
- **Логотипы брендов** (Codex, Claude, ElevenLabs, Remotion, Storybook, HeroUI, Pinterest, posts.design) — SVG внутри HTML-pill.
- **Плитки HeroUI, чат, карточки Telegram** — свёрстаны кодом.
- **Миниатюры «вариантов» в чате** — уменьшенные сцены этого же ролика; ранние варианты нарочно плохие (плоские цветные блоки, один с засечковым шрифтом).
- **3D «clay toy» картинки** на цветных плитках — Pinterest или GPT-image.
- **Превью posts.design** — кадры чужих роликов + HTML-бейджи «NN.NM VIEWS».
- **Memoji-аватар автора** и **SVG-курсор macOS**.

## 8. Ритм
- ≈18 экранов за 44 с — новый экран каждые ≈2.4 с. Всего ≈2–3 визуальных события в секунду; пик в чате (≈1.6 сообщения/с + скролл) и на холсте (pop + дорисовка + пан).
- Пауз почти нет: в паузах речи (0.3–0.4 с) идёт переход или «дозревает» визуал (stagger сеток, лента posts.design, дорисовка пунктира).
- Самый долгий «статичный» участок — 15.6–17.3 с на развилке Codex/Claude, но и там идёт дорисовка линий.
- Переходы 6–12 кадров, появления 5–9 кадров: ритм «щелчков» ≈ каждые 8–15 кадров.

## 9. Уникальность (против шаблонных Remotion-роликов)
1. **Метафоры, а не иконки:** иллюминатор = «взлёт» блога с датой в окне, балаклава = «без лица», ключ = «настроить», тумблер = «на автомат». Каждый смысл — один крупный предмет.
2. **Zoom-through в предмет:** небо из иллюминатора становится фоном следующей сцены. Шаблоны так не делают — там crossfade или slide.
3. **Инструкция по стеку как блок-схема**, по пунктиру которой едет камера с motion blur и zoom-dip. Ветвления — это буквально «здесь или здесь, но лучше здесь».
4. **Pill → живой UI:** pill ElevenLabs раскрывается в правдоподобную карточку Text to Speech, в поле которой — текст этого же ролика.
5. **Мета-шутка в чате:** «варианты» агента — кадры этого же ролика; ранние нарочно уродливые, один с «не тем» засечковым шрифтом.
6. **Четыре фоновых «мира»** при одном шрифте и одной системе pill/карточек — разнообразие без потери целостности.
7. **Blur как универсальный клей:** слова, pop-ы, переходы, пан камеры — всё через blur. Это даёт «дорогую», кинематографичную мягкость.
8. **CTA как интерактивная демонстрация:** курсор проходит путь «профиль → ссылка → канал → бот → мини-приложение» с морфингом одной карточки.
9. **Лаконичный нижний регистр:** 2–4 слова на экране, крупно — выглядит как Apple keynote, а не как субтитры.

## 10. Рецепт воспроизведения (Remotion)

**Подготовка:**
1. Сценарий → ElevenLabs v3 → mp3; Whisper (word-level) → `words.json` `{word, start, end}`.
2. Для каждой фразы задать: сжатый заголовок (2–5 слов), опорное слово для каждого визуального события, тип сцены, ассет.
3. Композиция 1080×1920, 30 fps; `<Audio>` на всю длину; сцены — `<Sequence>` с перекрытием 6–10 кадров под переходы.

**Библиотека компонентов:**
- `Background`: `graphite` + сетка с радиальной маской, `sky` + noise, `violetRadial`, `white` + сетка; смена фона — отдельным слоем.
- Текст: `BlurTitle` (привязка к `words.json`, пропс `pushY`), `Subline` + `BrandIcon`, `HighlightPill`, `ColorWord`.
- Появления: `RiseIn`, `Pop`, `ToolPill`, `DashedPath` (draw-on, развилки и слияния Безье).
- Камера и переходы: `CameraCanvas`, `ZoomThrough`, `WhipPan`, `Recede`, `BgRamp`.
- Мокапы и UI: `PhoneMockup`, `PhoneCarousel`, `MorphCard` (пресеты TTS / TG-профиль / канал / бот / мини-приложение), `StaggerGrid`, `Masonry` (с автоскроллом), `ChatStack`, `Cursor` (путь по точкам + click-колбэк), `Toggle`.

**Ассеты:** 3–4 предмета-метафоры из GPT-image в едином стиле («фотореалистичный 3D-объект, мягкий студийный свет»), SVG-логотипы, Memoji, скриншоты профилей, 6–8 «clay toy» картинок.

**Сборка:**
1. Хук ≤2.5 с: заголовок blur-in → RiseIn предмета-метафоры → Pop детали (дата) → ZoomThrough в сцену с цифрами.
2. Новый экран каждые 2–3 с, чередуя фоны; не больше двух одинаковых переходов подряд.
3. Инструкцию из N шагов собрать на одном `CameraCanvas` с пунктиром; один pill раскрыть в `MorphCard`.
4. Итерации — `ChatStack` с миниатюрами собственных сцен (рендерить сцены уменьшенными через `<Freeze>`).
5. CTA — `MorphCard` + `Cursor`, клики на словах «сюда / потом сюда / и сюда», без аутро.
6. Рендер `--crf 18`; `@remotion/motion-blur` — только для сцен с паном.
