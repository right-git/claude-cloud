# Общие ошибки видеопроизводства и обязательные проверки

Источник: исправления в проекте Jev, сентябрь 2026. Это общий стандарт качества,
а не отдельный формат видео. Читать вместе с выбранным workflow перед новым видео
и перед правками. Пользовательские указания имеют приоритет; формат определяет
стиль, сервисы и режим согласований. Синий цвет, тёмная сетка, отсутствие субтитров
и конкретный голос из Jev **не становятся настройками всех видео**.

## Проверки по этапам — выполнять до показа пользователю

### До платных вызовов

- Зафиксированы сценарий, разрешение, сервис, голос, произношение, формат и FPS.
- Схема инструмента проверена в текущем подключении. Конфигурация MCP не доказывает доступ.
- Уже полученное разрешение не запрашивается повторно. Пользовательская правка конкретной реплики разрешает её замену; остальные реплики сохраняются.
- Есть план ограниченного исправления, чтобы не тратить деньги на повтор всей озвучки.

### До полного монтажа

- Все длительности в плане и спецификациях указаны в секундах; перенесённые «кадры» пересчитаны с учётом fps источника (G28).

- Исследование подтверждает примеры. Иллюстративные данные не выданы за реальные результаты компаний.
- Принятый голос сохранён локально и проверен на полноту. Произношения проверены отдельно.
- Определён формат; его движение проверено коротким рендером, если workflow требует такого согласования.
- Ресурсы пригодны для механики сцены, соответствуют утверждённому стилю и не дублируют отвергнутые версии.

### До каждого итогового рендера

- Изменены только запрошенные области и их реальные зависимости: геометрия клика, длина клипа, синхронизация, микс.
- Проверены входы, исходы, чтение результата, переходы и safe zones. Проверяется и анимация, и окно видимости сцены.
- После замены звука проверены актуальные слова/тайминги, стыки и последняя фраза.
- Голос, музыка и SFX реально включены, уровни измерены по голосовым окнам, включая CTA. Цель баланса берётся из выбранного workflow; не назначать один gain всем трекам.
- Существуют все используемые файлы. В итоговой сборке нет отвергнутого голоса, временного аватара или скрытого устаревшего ресурса.

### Перед отправкой

- Пройдена режиссёрская (творческая) самопроверка выбранного workflow по закодированному MP4 (G29).
- Все пункты `media/change-log.md` текущего раунда закрыты проверкой по кадру или явно перечислены как невыполненные с причиной (G25).
- В изменённых местах нет сирот и нарушений инвариантов формата (G26, G27).
- Проверены реальные dimensions/FPS/codecs/duration и декодированные кадры итогового MP4.
- Для изменённого движения осмотрены начало, середина, конец и конкретные кадры действия; для нового полного видео — все сцены.
- Обновлены необходимые review-файлы, сведения о дубле и QA. Пользователь получает точную ссылку на новый файл.
- Не утверждать «прослушал», «самая новая модель», «всё проверено», если нет соответствующего доказательства.
- Незавершённый голос/аватар нельзя обозначать как завершённый финал. При сбое остановить зависимый этап, назвать наблюдаемую проблему и продолжить разрешённую независимую работу.

## Обязательства без лишних согласований

Этот файл не создаёт новых ворот согласования. Действуют разрешения пользователя
и выбранный workflow. Исправления и проверки не перекладывать на пользователя.
При его просьбе остановить работу с сервисом не искать обходы. При восстановлении
подключения перепроверить доступ и продолжить уже разрешённую задачу.
