## 4. Каталог анимаций

1. **Blur-in слова.** opacity, blur 8–10→0, translateY 8–12→0; 6–8 кадров, ease-out (.2,.8,.2,1); пословно по Whisper. Иногда внутри слова идёт градиентный wipe.
2. **Layout-shift строк.** Spring 8–10 кадров без overshoot; старые строки тускнеют до 0.4 и уходят вверх.
3. **Pop объекта.** scale 0.6→1.08→1 + blur 6→0, ~10 кадров, spring (damping 12, stiffness 180).
4. **Выделение слова.** Плашка растёт по ширине за 4–5 кадров, ручки делают pop на 2 кадра позже.
5. **3D-карусель.** Радиус ~350, perspective 1200, ~25°/s линейно; дальние карточки темнее и размыты.
6. **FLIP папки в заголовок окна.** ~12 кадров, на пике скорости blur ~4 px.
7. **Материализация окна.** scale 0.96→1 + opacity; затем stagger сетки по 2 кадра.
8. **Split карточки (фирменный).** Новая карточка рождается из-за старой (z-index ниже, opacity 0.4→1) и едет вправо, старая одновременно влево. Spring 12–14 кадров, композиция остаётся по центру.
9. **Ghost-рамка + камера вверх.** Сдвиг 40–60 px, ~15 кадров, ease-in-out.
10. **Stagger списка.** Интервал 12–15 кадров, blur-in + translateX −6→0.
11. **Shimmer-sweep по списку.** Gradient + background-clip:text, ~10 кадров.
12. **Karaoke-подписи.** Белая «волна» шириной 3–4 буквы идёт слева направо.
13. **Пунктирная дуга «N шаг».** Точки 3 px с шагом 10 px, подпись повёрнута по касательной; рисуется ~10 кадров.
14. **Chain-slide плашек.** Зигзаг dx ±130, dy +215, spring ~12 кадров.
15. **Idle float.** rotate ±0.3–0.6°, translate ±2 px, период 3–4 s, у каждой карточки своя фаза.
16. **Crossfade смены темы.** 4 кадра.
17. **Подъём заголовка + рост карточки.** ~12 кадров.
18. **Курсор + click ripple.** Курсор scale 1→0.85→1, кольцо scale 0.5→1.6 с fade.
19. **Height-morph карточки по шагам.** ~8 кадров, контент меняется через blur.

**Remotion — ключевые приёмы**

(а) Пословный blur-in

## 6. Переходы и камера

- **Холст непрерывный.** Новые элементы рождаются из старых; камера сдвигает весь мир по translateY на 40–75 px. Зум только у папки, 7.9–8.4 s.
- **Переходы между сценами:**
  1. crossfade 4 кадра;
  2. текст → папка;
  3. папка → окно (shared element);
  4. hard cut 10.47, папка остаётся героем кадра;
  5. сетка тускнеет → из неё выходит иконка Заметок;
  6. fade пайплайна + blur-in заголовка;
  7. одна карточка меняет высоту по шагам.
- **Объект-мост всегда переживает смену сцены.**

## 8. Ритм

- **Плотность:** ~70–80 событий за 43 s, это ~1.7–2 в секунду. В хуке 4–5 в секунду.
- **Самые плотные участки:** 0–2.5 s и 5.9–10.4 s.
- **Паузы:**
  - 31–35.4 s (4.4 s) — работают только shimmer и float;
  - 2.5–5.8 s — работает карусель.
- **Статичных кадров нет.**

## 9. Уникальность

1. Мета-сюжет: система показывает сама себя, в карусели играют собственные прошлые ролики.
2. Файловая структура подана как дизайн-объект: хромовые иконки, стеклянные карточки.
3. Смена тёмной темы на светлую и обратно под шутку.
4. Эмодзи-цензура.
5. Метафора выделения текста в редакторе.
6. Рост композиции «из себя» вместо въездов из-за края экрана.
7. Тактильные микродетали: shimmer, karaoke, float, затемнение перед сменой сцены.
8. CTA как интерактивное демо пути до бота.
9. Почти монохром с 1–2 акцентами, всё строчными.
