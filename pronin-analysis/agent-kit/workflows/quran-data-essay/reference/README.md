## Механики (→ §5 workflow)

1. Корпус-сетка «each dot is one verse · 6,236» (v1 0:05).
2. Подсветка вхождений + счётчик, пара A = B с кольцевой волной (v1 0:09–0:20, 0:24–0:32).
3. Карточка стиха: арабский + перевод + ссылка, слово подсвечено в обоих (v1 0:30, 0:39).
4. Ряд-счёт: 12 точек по кругу = 12 месяцев (v1 0:36).
5. Ось 610–632 CE, точки падают в порядке откровения, Makkah/Madinah (v2 0:20–0:40).
6. Перестановка хронология → мусхаф (v2 0:40–0:50).
7. Полосы секций суры, складывание, скобки пар (v3 0:05–1:00).
8. Финальная карточка с логотипом из точек (v1 0:46, v3 1:10).
