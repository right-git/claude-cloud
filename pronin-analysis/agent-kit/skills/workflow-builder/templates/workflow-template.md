## 0. Как пользоваться этим файлом

Приоритет при конфликте: указание пользователя в сессии → U01–U16 и инварианты §3 →

Все длительности в секундах; кадры — только вместе с fps.

## 2. Принятые настройки этой серии

Канал, CTA, логотип, голос (ID), музыка, словарь произношений (D4) — использовать без
повторного запроса.

## 3. Инварианты стиля — проверять в каждой сцене

Нумерованный список I1…In. Каждый инвариант: правило с числом + как проверить.
Обязательно покрыть: фон (E1, один глобальный слой), палитру и акцент (E2–E3),
типографику и кегли (E4–E5), сетку кадра и зоны (E6–E8, B5), лимит элементов и запреты
(E9), текст на экране vs речь (D3).

Токены сетки (пример заполнения):
```
поля 64 | контент 952 (x 64–1016) | колонки 4×214, гаттер 32 | ширины объектов 952/460/214
заголовок: центр x=540, верх y=300 | объект: y 640–1400 | шкала отступов 16/24/32/48/64
карточка: padding 48, радиус 32 | текст ≥ 36 px, цифры 140–160 px
```

## 10. Этапы и согласования (H1, H2)

Нумерованные этапы с артефактом каждого этапа (`media/spec.md`, `media/research.md`,
`media/pronunciation.md`, scene-plan с триггер-словами, пилот 3 фрагмента, рендер) и где
нужен «ок» пользователя.

## 11. Режиссёрская самопроверка (H3, H4)

Перед каждым показом, по encoded MP4:
- контактные листы, кадры швов, кадр 360 px ширины;
- `scripts/qa/layout-lint.js` на кадре покоя каждой сцены → `[]`;
- кадры 0 / 2.5 с / середина / последний с наложенной сеткой;
- фон: средний цвет в одних и тех же точках во всех сценах совпадает ±2;
- голос: все слова из `pronunciation.md`, хвост CTA, нет обрывов;
- отчёт в трёх категориях: техническая / визуальная / речевая.
