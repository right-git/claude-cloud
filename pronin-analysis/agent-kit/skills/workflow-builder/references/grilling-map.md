# Карта grilling: что обязательно решить для workflow

Порядок веток = порядок вопросов (поздние зависят от ранних). **Обязательные** пункты
помечены `*` — без них grilling не завершается. Колонка «Из референса» — что можно
измерить по `reference-analysis.md` и предложить как рекомендуемый ответ вместо открытого
вопроса.

Формат записи в `decisions.md`: `ID | решение | значение | источник | уверенность`.

## A. Назначение и границы

| ID | Решение | Из референса | Хороший ответ выглядит так |
|---|---|---|---|
| A1* | Для каких роликов формат (тип контента) и для каких — нет | частично | «объяснение одной технологии / новости AI; не топы, не интервью» |
| A2* | Канал, язык, аудитория | — | «milanko.ai, русский, новички в AI» |
| A3* | Чем формат отличается от уже существующих workflow | — | одна строка; если ничем — расширять существующий |
| A4* | Суть формата одной фразой | да | «голос говорит — крупный объект делает именно это» |
| A5 | Что из референса брать нельзя (бренд, персонажи, CTA) | да | список |

## Подсказки для вопросов

- Спрашивать про то, что пользователь **видит**: «на кадре 0:04 референса заголовок
  ≈110 px и по центру — так же?», а не «какой кегль?».
- Предлагать 2–3 варианта макетами, когда вкус не формулируется словами.
- Каждый ответ «как в референсе» превращать в число из замера.
- Если пользователь говорит «не знаю» — записать рекомендуемый ответ с источником
  `дефолт скилла`, уверенность `средняя`, и вынести в пилот на проверку.
