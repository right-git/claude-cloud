# Разбор видео-референса в измеренные числа

Цель — не «описать вайб», а получить числа и механики, которые потом станут правилами
workflow. Всё, что записано в сводку, подтверждается таймкодом.

Рабочая папка: `workflows/<slug>/reference/` (не `/tmp`). Сырые кадры — в
`workflows/<slug>/reference/frames/` (можно удалить после разбора, кроме ключевых кадров).

## 1. Паспорт ролика

```bash
ffprobe -v error -show_entries stream=codec_type,width,height,r_frame_rate -show_entries format=duration -of json IN.mp4
```
Записать: разрешение, fps, длительность, есть ли музыка/голос.

## 2. Кадры

```bash
# обзор: 2 кадра/с, листы 10×3 (15 с на лист)
ffmpeg -i IN.mp4 -vf "fps=2,scale=180:-2,tile=10x3" frames/sheet_%02d.jpg
# границы сцен (резкие смены)
ffmpeg -i IN.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time
# плотно вокруг перехода: 10 кадров/с, 1.2 с
ffmpeg -ss T-0.6 -t 1.2 -i IN.mp4 -vf "fps=10,scale=270:-2,tile=12x1" frames/seam_T.jpg
# полный размер для замеров
ffmpeg -ss T -i IN.mp4 -frames:v 1 frames/full_T.png
# поднять тени, чтобы увидеть фон/сетку
ffmpeg -i frames/full_T.png -vf "curves=all='0/0 0.08/0.5 0.25/0.8 1/1'" frames/boost_T.png
```

Смотреть листы глазами. Для каждой сцены записать: время, что за объект, какое действие,
какой текст на экране, как вошла и ушла.

## 3. Звук и текст

- Транскрипция с пословными таймкодами (Deepgram из проекта или локальный whisper).
- Посчитать: темп (слов/с), паузы между фразами (медиана), есть ли музыка и её уровень
  относительно речи, какие события озвучены SFX.
- Сопоставить слова с событиями на экране: на сколько событие опережает/отстаёт от слова
  (медиана по 10+ событиям).

## 4. Замеры (таблица в `videos/vN.md`)

| Параметр | Как мерить |
|---|---|
| Цвет фона, поверхностей, текста, акцента | средний RGB в окне 40×40 px на полном кадре (hex) |
| Паттерн фона | boost-кадр: тип (точки/линии), шаг px, размер точки, маска, движется ли (сравнить 2 кадра через 2 с) |
| Кегли | высота строчной «х» и прописной в px на полном кадре → кегль; главный, пояснение, UI, цифры |
| Поля и ширина контента | крайние x всех элементов на 10+ кадрах покоя → поле слева/справа, ширина |
| Вертикальные зоны | y верха заголовка, y верха/низа объекта, пустые зоны |
| Отступы, радиусы | на 3–5 карточках: padding, радиус, гаттер между элементами |
| Элементов в кадре | максимум и медиана по кадрам покоя |
| Длительность «плана» | интервалы между сменами кадра/состояния: медиана и максимум |
| Переходы | тип (cut / blur / масштаб / морф / мост), длительность, перекрытие |
| Анимация текста | появление (печать/фейд/маска), скорость с/символ |
| Синхронизация | сдвиг событие − слово (медиана) |
| Хук | что видно на 0 / 1 / 2.5 с, понятно ли без звука |
| Структура | блоки ролика с таймкодами и долей длины |

Шрифт: если узнаваем — назвать и найти ближайший доступный; иначе описать признаки
(гротеск/антиква, ширина, контраст) и предложить 2–3 кандидата в grilling.

## 5. Сводка `reference/README.md`

1. Таблица параметров: медиана, разброс, в скольких роликах встречается, таймкоды.
2. Механики: каждая — название, что делает, в каких роликах/таймкодах, как выглядит
   по шагам (исходное → действие → результат).
3. Драматургия: общий скелет, варианты.
4. Только в одном ролике — отдельным списком (не правило, кандидат на вопрос).
5. Не удалось измерить — отдельным списком (уйдёт вопросом в grilling).
6. Что нельзя копировать (бренд, персонажи, CTA, фирменные экраны).

Пересчитать кадры в секунды: если референс 30 fps, а рендер 60 fps — все длительности
записывать в секундах.
